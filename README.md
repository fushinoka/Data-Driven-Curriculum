# Data-Driven Curriculum

Веб-дашборд для методистов: показывает результаты тестов по темам, помогает найти сложные разделы и пересмотреть распределение учебных часов.

## Что можно сделать

- сравнивать результаты по темам и учебникам;
- загружать данные из CSV или XLSX и проверять формат файла;
- показывать проблемные темы и сводные показатели;
- строить вариант перераспределения часов в рамках заданных ограничений;
- показывать динамику, если в файле есть данные минимум за два периода;
- экспортировать HTML-отчёт с результатами и пояснениями.

Подсказки и расчёт часов работают по фиксированным правилам. ИИ-модель не используется; методист проверяет предложения и принимает решение.

## Запуск

Откройте `index.html` в браузере. Устанавливать пакеты и собирать проект не нужно. Для графиков, стилей и шрифтов понадобится интернет: страница загружает их через CDN.

Чтобы попробовать импорт, выберите `demo_data.csv` в блоке «Данные и настройки методики». В файле две условные группы учебников и два периода, поэтому можно посмотреть сравнение и динамику.

## Формат данных

Обязательные колонки: `class`, `subject`, `textbook`, `topic`, `score`, `students`, `hours`. Колонки `period` и `students_below` необязательные. Разделитель в CSV может быть точкой с запятой, запятой или табуляцией. Числа `score` задаются от 0 до 100.

В `students_below` укажите фактическое число учеников ниже порога, если такие данные есть в источнике. Если колонки нет, приложение покажет приблизительную оценку, а не подсчёт учеников.

## Как читать результаты

Все цифры и названия «Учебник A/B» в демо условные. Порог 65%, веса индекса и ограничения по часам нужны для показа сценария и не являются официальной методикой.

Сравнение показывает разницу только в этом наборе данных. Оно не доказывает, что её вызвал учебник: на результаты также влияют учитель, состав классов и сложность теста. Число учеников и школ считается по группам. Если одни и те же ученики или школы есть в нескольких группах, их посчитают повторно.

Вариант сохраняет общий объём часов и распределяет их по заданным правилам. Он не предсказывает, изменятся ли результаты после переноса часов. Перед использованием проверьте расчёты на сопоставимых данных вместе с методистами.

## Данные и конфиденциальность

Файл обрабатывается в браузере и не отправляется на сервер. Библиотеки и шрифты загружаются через CDN, поэтому нужен интернет. Не добавляйте реальные данные учеников в публичное демо или репозиторий.
