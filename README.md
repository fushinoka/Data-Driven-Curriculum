# Data-Driven Curriculum

Прототип дашборда для методистов. Он показывает результаты тестов по темам, помогает найти разделы ниже выбранного порога и подготовить вариант распределения учебных часов.

## Что умеет прототип

- сравнивать результаты по темам и учебникам;
- загружать данные из CSV или XLSX и проверять формат файла;
- показывать проблемные темы и сводные показатели;
- строить вариант перераспределения часов в рамках заданных ограничений;
- показывать динамику, если в файле есть данные минимум за два периода;
- экспортировать HTML-отчёт с результатами и пояснениями.

Подсказки и расчёт часов основаны на правилах из прототипа, а не на ИИ-модели. Это варианты для обсуждения; решение принимает методист.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка пакетов не нужны. Для графиков, стилей и шрифтов требуется интернет: они загружаются через CDN.

Чтобы попробовать импорт, выберите `demo_data.csv` в блоке «Данные и настройки методики». В нём две условные группы учебников и два периода, поэтому можно посмотреть и сравнение, и динамику.

## Формат данных

Обязательные колонки: `class`, `subject`, `textbook`, `topic`, `score`, `students`, `hours`. Колонки `period` и `students_below` необязательные. Разделитель в CSV может быть точкой с запятой, запятой или табуляцией. Числа `score` задаются от 0 до 100.

В `students_below` можно указать фактическое число учеников ниже порога по критерию, принятому в источнике данных. Если этой колонки нет, прототип показывает приблизительную оценку, а не фактическое число.

## Как читать результаты

Демо-цифры и названия «Учебник A/B» условные. Порог 65%, веса индекса и ограничения по часам — настройки для показа сценария, а не официальная методика.

Сравнение учебников описательное. Разница в результатах сама по себе не доказывает, что её вызвал учебник: на неё могут влиять учитель, состав классов и сложность теста. Число участников суммируется по группам и может включать повторно учтённых учеников или школы.

Вариант часов сохраняет общий объём и распределяет его по заданным правилам. Он не прогнозирует, как перенос часов повлияет на результаты. Перед реальным применением методику нужно проверить на сопоставимых данных вместе с методистами.

## Данные и конфиденциальность

В текущем прототипе нет серверной загрузки: выбранный файл обрабатывается в браузере. Для работы страница загружает библиотеки и шрифты через CDN. Не используйте реальные данные учеников в публичном демо или репозитории.
