# Data-Driven Curriculum

Этот прототип помогает методистам разбирать результаты тестов по темам, замечать сложные разделы и обсуждать, как распределить учебные часы.

## Что можно сделать

- сравнивать результаты по темам и учебникам;
- загружать данные из CSV или XLSX и проверять формат файла;
- показывать проблемные темы и сводные показатели;
- строить вариант перераспределения часов в рамках заданных ограничений;
- показывать динамику, если в файле есть данные минимум за два периода;
- экспортировать HTML-отчёт с результатами и пояснениями.

Подсказки и расчёт часов строятся по заданным правилам, без ИИ-модели. Это отправная точка для обсуждения; окончательное решение принимает методист.

## Запуск

Откройте `index.html` в браузере. Устанавливать пакеты и собирать проект не нужно. Для графиков, стилей и шрифтов понадобится интернет: страница загружает их через CDN.

Для демо выберите `demo_data.csv` в блоке «Данные и настройки методики». В файле есть две условные группы учебников и два периода: можно посмотреть сравнение и динамику.

## Формат данных

Обязательные колонки: `class`, `subject`, `textbook`, `topic`, `score`, `students`, `hours`. Колонки `period` и `students_below` необязательные. Разделитель в CSV может быть точкой с запятой, запятой или табуляцией. Числа `score` задаются от 0 до 100.

В `students_below` укажите фактическое число учеников ниже порога, если такие данные есть в источнике. Если колонки нет, приложение покажет приблизительную оценку, а не подсчёт учеников.

## Как читать результаты

Все цифры и названия «Учебник A/B» в демо условные. Порог 65%, веса индекса и ограничения по часам нужны для показа сценария и не являются официальной методикой.

Сравнение показывает только разницу в этом наборе данных. По нему нельзя заключить, что разницу вызвал учебник: на результаты также влияют учитель, состав классов и сложность теста. Число учеников и школ суммируется по группам, поэтому один и тот же участник может посчитаться несколько раз.

Предложение по часам сохраняет общий объём и следует заданным правилам. Оно не предсказывает, улучшатся ли результаты после переноса часов. Перед применением на практике проверьте расчёты на сопоставимых данных вместе с методистами.

## Данные и конфиденциальность

Выбранный файл обрабатывается в браузере, серверной загрузки нет. Сама страница загружает библиотеки и шрифты через CDN. Не добавляйте реальные данные учеников в публичное демо или репозиторий.
